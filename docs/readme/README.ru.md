# orc

**Очередь задач для Claude Code.** orc запускает каждую задачу в отдельном git worktree через `claude --bg`, проверяет результат вашей командой и по одной вливает готовые ветки в вашу ветку.

> Это краткая версия. Полная документация на английском.

## Зачем нужен orc

- **Одна задача, один worktree.** Каждая задача стартует в своём worktree через `claude --bg`: сессии никогда не делят контекст и рабочую копию.
- **Слияние по FIFO, строго по одной.** Готовые ветки вливаются через `--no-ff` в том порядке, в каком стали готовы. Если ветка занята, задача ждёт в очереди, а не падает.
- **Мелкие конфликты решает их автор.** При конфликте orc возвращает его той же сессии, которая написала код: она знает, почему код такой.
- **Ваша собственная подписка.** Сессии идут через ваш Claude Code CLI на вашей машине и расходуют подписку, которая у вас уже есть.

## Возможности

- **Канбан-доска** с колонками Backlog, To do, In progress и Done. Всё, что ждёт вас (вопрос, сбой, конфликт), собирается в полосе «Waiting for me». Массовые действия и сохранённые виды.
- **Автодиспетчер.** Раз в 30 секунд берёт задачи из «To do» с учётом лимитов воркеров и зависимостей.
- **Проверка перед слиянием.** Ваш `verify_cmd` (тесты, линтер, сборка) запускается в worktree задачи. С красной проверкой ничего не вливается.
- **Агенты.** Модель, усилие, режим разрешений и промпт под именем и аватаром. Агент не привязан к проекту, у него своя страница с активностью в реальном времени, и у него может быть собственная память.
- **Чаты с агентами** в любом проекте или вне проектов, в приватном worktree, откуда ничего не вливается. Лид проекта видит доску и предлагает задачи, которые попадают в бэклог только с вашего согласия.
- **Агенты, которые сами планируют работу.** Сессия, чат или лид может разбить большую фичу на связанные карточки через `orc task add`, `batch` и `link`, выстроить их по зависимостям и этапам, уснуть через `orc task wakeup` и проснуться, когда завершатся подзадачи. Диспетчер запускает цепочку сам.
- **Рутины.** Инструкция плюс расписание (каждые N минут, часов или дней, либо cron). Проект не нужен: без него каждый запуск становится чатом с агентом.
- **Вопросы и ответы вживую.** Запросы разрешений, вопросы и утверждение плана появляются на карточке, а ваш ответ попадает в ту же работающую сессию.
- **Токены, лимиты и сводка.** Токены по карточкам, 5-часовой и недельный лимиты аккаунта, сводка с долей успехов, временем и стоимостью.
- **Шесть языков интерфейса** (английский, испанский, французский, немецкий, португальский и русский), светлая и тёмная темы.

## Как это работает

1. Добавьте проект: путь к git-репозиторию, `verify_cmd` и лимит воркеров.
2. Создайте агента и карточку, назначьте её агенту и переведите в «To do».
3. Диспетчер создаёт worktree на новой ветке `orc/task-N` и запускает `claude --bg` с заданием.
4. Агент завершает работу командой `orc task done`, orc запускает `verify_cmd`. Сбой возвращается в ту же сессию.
5. Проверенные задачи вливаются по FIFO через `git merge --no-ff`. Конфликты возвращаются сессии, написавшей код, а затем вам.

## Быстрый старт

Нужны macOS или Linux, Python 3.12+, [uv](https://docs.astral.sh/uv/), Node.js 20.19+ или 22.12+, git 2.38+ и авторизованный CLI [Claude Code](https://github.com/anthropics/claude-code).

```bash
git clone https://github.com/alimardonbegov/orc.git
cd orc
make setup          # uv sync, npm ci, web UI build
uv run orc doctor   # environment check
make start          # run the server in the background
make stop           # stop it
```

Откройте <http://127.0.0.1:8765>, добавьте проект, создайте карточку и перетащите её в «To do».

**Безопасность.** orc выполняет код от вашего имени без присмотра: в этом его задача. Он слушает только loopback; никогда не открывайте порт наружу. Прочитайте раздел [Security](../../README.md#security) до начала работы.
